BINGO

Stream Bingo

Free chat bingo for streamers. Viewers type !enter in chat to get a card, your mods call the words, and everyone follows their card fill in on a web page. Works with Twitch, Kick, YouTube and Rumble chat.

Download v1.2.0 (zip, 57 KB) View the code on GitHub

A zip file with everything in it. No installer and no extra packages. You only need Node.js 22.4 or newer.

What it does

Reads four chats at once

Twitch, Kick, YouTube and Rumble. No bot account or API keys needed.

Cards on a web page

Viewers search their name to see their card fill in live, and can save it as an image. Optionally they can tap squares to dab their own card, or mark it all themselves.

Points and wagers

Bingos and blackouts pay out. Viewers can wager with !enter 50. Weekly and all-time leaderboards.

Mods call the words

With !mark in chat, or on a mod page with its own password that can only call words.

Admin page

Start and end games, edit the word list, upload a card background, set payouts, and test commands without going live.

Your own look

Rename the game, pick colours and upload your own card background.

Get it running

  1. Install Node.js 22.4 or newer.
  2. Download the zip above and unzip it.
  3. Double-click start.bat on Windows, or run node server.js.
  4. Open http://localhost:3000/admin. The admin password is printed in the window the first time.
  5. Set your chat channels and word list on the admin page, then press Start new game.

The download comes with a sample word list and channel set up. Change them on the admin page before your first stream. To put it online for your viewers, see "Putting it on the internet" in the included README.

Stream Bingo. Kick, YouTube and Rumble chat are read through the same feeds their own websites use, which those sites can change without notice.
